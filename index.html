// LAUNCH SEQUENCE PROTOCOL

HOW IT WORKS

Deploy coordinate-targeted strikes in four operational steps, plus optional automated airspace defense.

  1. 01
    Step 01

    Deploy the Launch Pad

    Place the animated 3D Launch Pad on a clear firing site and position a Coordinate Terminal within a 5-block radius (v5.0.0+; 3 blocks in older versions).

  2. 02
    Step 02

    Load & Elevate Rails

    Right-click the pad to load a Standard or Heavy Missile onto the rails. For Heavy Missiles, right-click with an empty hand to raise the launcher vertically (90°).

  3. 03
    Step 03

    Lock Coordinates

    Enter target X and Z coordinates in the Coordinate Terminal (or Shift + Right-Click a block using the portable Remote Control).

  4. 04
    Step 04

    Trigger Ignition

    Activate the terminal with a Redstone signal (button/lever) or Right-Click the pad with the Remote Control to launch.

Optional Defense Step // COUNTER-BATTERY

Deploy an Anti-Air System

Protect your base by setting up an automated Anti-Air System stocked with Interceptor Missiles. It automatically fires to shoot down incoming threats—offering strong protection against Standard Missiles, though it struggles against the extreme terminal descent speed of Heavy Missiles.
